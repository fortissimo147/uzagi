# Tower of Green Pillars

Three.js の 3D 登り系アクション。ブラウザだけで動く。全3面。
絵はすべてコード生成（画像ファイルなし）。声だけ `voice/` の録音を使う。

## 動かす

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力（静的ホスティングにそのまま置ける）
npm test         # 物理・音・プレイ通し・全ステージの自動テスト
npm run standalone  # standalone/tower-of-green-pillars.html （1ファイル完結版）
```

Node 18 以上。`npm test` は playwright-core で Chromium を起動する。

## 操作

| 操作 | キー | タッチ |
| --- | --- | --- |
| 移動 | W A S D ／ ↑ ↓ ← → | 画面左の仮想スティック |
| ジャンプ | Space（Z / K でも） | 画面右の JUMP |
| 2段・3段ジャンプ | 着地してすぐまた Space | 同上 |
| しゃがむ | Shift（Ctrl / X / J でも） | 画面右の CROUCH |
| 幅跳び | 走りながら しゃがむ＋Space | 同上 |
| ヒップドロップ | 空中でしゃがむ | 同上 |
| 壁キック | 壁に触れながら Space | 同上 |
| カメラ | ドラッグ ／ Q E | 画面右側をドラッグ |
| ポーズ | P | — |
| 音の入切 | M | — |

移動はカメラ基準。W は「カメラから見て奥」へ進む。
2段・3段ジャンプは着地の 0.32 秒以内にまた跳ぶと段が上がる（空中で
もう一度押す方式ではない）。3段まで上がると次は1段目に戻る。

土管に入るとその面はクリア。次の面へ進み、3面を越えると通しのクリアになる。
コイン・得点・時間は面をまたいで積み上がり、ライフだけ面の頭で満タンに戻る。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `src/main.js` | 起動・ゲームループ・タイトル／クリア／ゲームオーバーの進行 |
| `src/physics.js` | AABB の当たり判定と移動解決（描画から独立、テスト可能） |
| `src/level.js` | ステージ定義と生成（足場・ギミック・敵・舞台の色） |
| `src/player.js` | プレイヤーの入力反映・状態遷移・アニメーション |
| `src/rabbit.js` | 主人公モデルをジオメトリから組み立てる |
| `src/enemies.js` | 敵とギミック（歩行敵・火柱・鉄球） |
| `src/camera.js` | 追従カメラ |
| `src/input.js` | キーボードとタッチ入力 |
| `src/hud.js` | ライフ・コイン・画面表示 |
| `src/textures.js` | 手続き生成のテクスチャとマテリアル |
| `src/audio.js` | 効果音と声を WebAudio で合成 |
| `src/voicebank.js` | 録音音声の差し込み口（自動生成・手で編集しない） |
| `src/style.css` | 画面まわりの CSS |
| `voice/*.wav` | 主人公の声の素（切り出し済み。ここから voicebank.js を作る） |

テストは `test/` にある。`physics` は当たり判定、`audio` は曲と声のデータ、
`play` は1面の通し、`stages` は全ステージの地形とクリアの流れを見る。
`test/autopilot.mjs` は「目標へ走って崖の手前で跳ぶ」だけの簡易AIで、
`play` と `stages` の両方が区間のつながりを確かめるのに使っている。

`tools/standalone.mjs` はビルド結果を 1 枚の HTML にまとめる。
`tools/make-voicebank.mjs` は `voice/*.wav` を `src/voicebank.js` に取り込む
（入れてよいのは自分で録った音か、使う権利のある音だけ）。

## ステージ

| 面 | 名前 | 中身 |
| --- | --- | --- |
| 1 | Tower of Green Pillars | 緑の洞窟をまっすぐ登る。坂・火柱・動く床のひと通り |
| 2 | Molten Ironworks | 赤い工房。まず横に走らせて、昇降機で一気に上げる |
| 3 | Frozen Spire | 青い尖塔。足場を小さくして、細かい跳び移りを続けさせる |

面を足すときは `src/level.js` の `STAGES` に1つ書き足す。
`build(b)` に渡ってくる `b` に足場・坂・動く床・敵・コインを置く関数が
そろっていて、`theme` で空の色・光・背景の柱を決める。

寸法には決まりがある（`src/level.js` の頭に書いてある）。段差は 2.0 まで、
足場の隙間は 4.5 まで。横に動く床は乗っても運んでくれないので、
上へ渡す役は縦に動く床にする。`npm test` の `stages` が、足がかりに床が
あるか・そこに立てるか・区間を自動操作で越えられるかを機械的に見るので、
登れない面を作るとそこで落ちる。

## 主人公の声

`voice/` に8本の録音が入っていて、そのうち7本が12の動きに当たっている。
ファイル名は「何と言っているか」で、同じ発音が2本あるものは高さと長さで分けた。
どの声をどの動きに当てるかは `tools/make-voicebank.mjs` の `VOICE` 表にある。

| 録音 | 長さ | 当たっている動き |
| --- | --- | --- |
| `ya-short.wav` | 0.28秒 | 敵を踏む／ヒップドロップ |
| `ha-rise.wav` | 0.39秒 | 2段ジャンプ／壁キック |
| `ha.wav` | 0.46秒 | 幅跳び／ライフ回復 |
| `ya-rise.wav` | 0.51秒 | 3段ジャンプ／ゴール |
| `yaha.wav` | 0.60秒 | ジャンプ（「やは」と続けて言った録音そのもの） |
| `hah.wav` | 0.68秒 | 落下中の悲鳴／被弾（「はっ！」） |
| `uma-long.wav` | 1.20秒 | ゲームオーバー |

`uma.wav` はどの動きにも当たっていない（今のところ出番なし）。

ジャンプは「やは」と1本で鳴る。続けて2段ジャンプすると、そのあとに
「は」（`ha-rise`）が続くので「やは・は」と重なって聞こえる。

着地の「ふっ」と立ち止まりの「ん…」は息の音なので、叫びを当てず
`src/audio.js` の合成のままにしてある。

声そのものには手を入れていない（変速・移調なし）。切り出しでしたのは
前後の無音を詰めること、7本に共通の倍率をかけること、継ぎ目の
プチノイズ除けに数ミリ秒のフェードをかけること、この3つだけ。

当て先を変えるときは `VOICE` 表を書き換えて `npm run voicebank`。
録音そのものを替えるときは `voice/` のファイルを置き換えて同じコマンド。
同じ録音は何度当てても1回しか埋め込まないので、増やしても容量は変わらない。

## 別リポジトリへ移すとき

このディレクトリの中身をそのまま新しいリポジトリの直下に置けば動く。
相対パスの外への参照はない。声は `src/voicebank.js` に data URI で
埋め込んであるので、ビルド結果も1枚のHTMLも単体で鳴る。
依存は `three` と、開発用の `vite` / `playwright-core` だけ。
